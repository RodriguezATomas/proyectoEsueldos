CSS GLOBAL
Cargar css/estilos.css una sola vez, después del CSS de Elementor, mediante el tema hijo, Elementor Custom Code o un plugin de CSS personalizado. No pegarlo dentro de cada widget.

JAVASCRIPT GLOBAL
Cargar js/scripts.js una sola vez al final del body/defer mediante Elementor Custom Code o el tema hijo. El script conserva el comportamiento original de megamenús y testimonios.

CONFIGURACIÓN DE ELEMENTOR
- Usar una página de ancho completo, preferentemente Elementor Canvas para evitar header/footer duplicados.
- Crear un contenedor por bloque, todos en ancho completo (100%).
- Establecer margin, padding, gap y separación entre widgets en 0.
- No aplicar ancho máximo, fondo, tipografía, borde ni efectos desde Elementor.
- Mantener los widgets en el orden indicado.
- Desactivar el título de la página y cualquier espaciado automático del tema.

FUENTES EXTERNAS
- Los @font-face y sus URLs originales permanecen dentro de css/estilos.css.

RIESGOS DETECTADOS
- Las rutas relativas de imágenes, videos y enlaces deben existir con la misma estructura en WordPress o resolverse desde el dominio correspondiente.
- Elementor y el tema pueden agregar estilos globales a body, botones, enlaces y encabezados; por eso se recomienda Canvas y cero espaciado.
- El header usa position:absolute y megamenús; debe cargarse antes del hero.
- El slider requiere que scripts.js se cargue después de los bloques HTML.
- El video autoplay depende de las políticas del navegador; conserva muted y playsinline.
